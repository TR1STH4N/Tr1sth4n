# Tr1sth4n — Creative Portfolio

A single-page portfolio for Tr1sth4n, featuring creative work, photography,
videography, video editing, and Minecraft server projects.

## Files

```text
.
├── .github/
│   └── workflows/
│       └── pages.yml
├── assets/
│   └── README.txt
├── .nojekyll
├── index.html
└── README.md
```

- `index.html` — the complete portfolio (HTML, CSS, and JavaScript).
- `assets/` — place images, GIFs, and other media here if you add them later.
- `.nojekyll` — tells GitHub Pages to serve files without Jekyll processing.
- `.github/workflows/pages.yml` — automatically deploys the site when you push to `main`.

## Publish with GitHub Pages

1. Upload the **contents** of this folder to the root of your GitHub repository.
2. Commit and push the files to the `main` branch.
3. Open your repository's **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions** as the source.
5. The included workflow will deploy the site. Open the URL shown in the Pages settings or in the workflow deployment.

## Update the portfolio

Edit `index.html`, commit the change, and push to `main`. GitHub Actions will deploy the update automatically.
